# Старые планы переименованы в схему `YYYYMMDD_HHMM_name`

Decided: 2026-09-06
Plan: —
Revised: —

## Context

Решение [Журналы ведутся по общим правилам](20260906_1247_journals_follow_shared_rules.md)
оставило семь планов `PLN-0001`–`PLN-0007` под старыми именами. В каталоге
получилось две схемы: `ls` сортирует `PLN-*` после `2026*`, и новые агенты
видят исключение из правила `plans.md` в каждом `AGENTS.md`. Планы никогда не
были в git (`docs/plans/` был в `.gitignore`), а при переносе в `.agents/plans/`
время рождения файлов потерялось, так что дату создания взять было неоткуда,
кроме `git reflog` и коммитов, которые эти планы реализовали.

## Decision

Все семь планов переименованы по `plans.md`: `YYYYMMDD_HHMM_short_task_name.md`.
Время в имени восстановлено по git и в каждом плане записано в строке
`Created:` сразу под `Plan file:`.

| Было       | Стало                                   | Источник времени                                  |
| ---------- | --------------------------------------- | ------------------------------------------------- |
| `PLN-0001` | `20260622_0441_scheduled_tasks`         | reflog: checkout `feat/scheduled-tasks`           |
| `PLN-0002` | `20260622_1200_sqlite_chat_event_log`   | reflog: checkout `feat/sqlite-message-log`        |
| `PLN-0003` | `20260622_1533_backend_layering`        | reflog: checkout `refactor/backend-layering`      |
| `PLN-0004` | `20260622_1558_in_code_docs_audit`      | reflog: `reset` на той же ветке между планами     |
| `PLN-0005` | `20260622_1627_full_docstring_coverage` | reflog: `reset` на той же ветке между планами     |
| `PLN-0006` | `20260622_1652_nonblocking_io`          | коммит `6a874ad`, закрывший три предыдущих плана  |
| `PLN-0007` | `20260629_2257_task_run_logging`        | коммит `c441b77`, состояние которого план описывает |

Ссылки на `PLN-000N` внутри планов и в `AGENTS.md` заменены на новые имена.
Содержание планов, статусы и чекбоксы не трогались.

## Why

- Одна схема имён в каталоге: правило без исключений короче, чем правило
  плюс оговорка в трёх `AGENTS.md`.
- Время из git, а не «00:00» и не сегодняшняя дата: имя должно сортировать
  планы по созданию, а reflog и коммиты дают порядок и день без догадок.
  Минуты для `PLN-0004`–`PLN-0007` — ближайшее проверяемое событие, а не момент
  создания файла; это записано в самих планах.
- Отвергнуто «оставить `PLN-*`» (решение от 12:47): аргумент «не переписывать
  историю» не работает, планы в git ещё не попадали.
- Отвергнуто «взять сегодняшнюю дату»: планы встали бы после нового плана
  `20260906_1300_*`, хотя созданы на два месяца раньше.

## Cost

- Время в именах четырёх планов приблизительное; точнее восстановить нельзя.
- Ссылки на `PLN-000N` в чатах и заметках вне репозитория больше не
  резолвятся; таблица выше — единственный указатель.
