# Ruff в полном наборе с четырьмя адаптациями под проект

Decided: 2026-09-06
Plan: `.agents/plans/20260906_1300_tooling_follows_python_and_ruff_rules.md`
Revised: —

## Context

Старый конфиг: 15 наборов, `pep257`, ignore для `S101`, `S110`, `E501`,
`ANN401`, `TC006`, `RET504`, `target-version` дублировал `requires-python`,
`ruff format` ни разу не применялся (61 файл из 91). Сухой прогон полного
набора из `~/.agents/rules/ruff.md` дал 298 находок; после формата и
safe-фиксов — 225.

## Decision

Конфиг из `ruff.md` (full: preview `DOC*`, `google`, per-file для тестов)
взят целиком. Отклонения, каждое с комментарием в `pyproject.toml`:

- `line-length = 100`: сигнатуры SDK и аннотации хендлеров aiogram.
- `ANN401` в ignore: `Any` на границах SDK/JSON и есть настоящий тип, 42 места.
- `TC001`–`TC003` в ignore: на 3.14 аннотации ленивые (PEP 649), перенос
  148 импортов под `TYPE_CHECKING` ничего не даёт и делается только
  unsafe-фиксами, которые агент не применяет; dataclass и pydantic читают
  аннотации в рантайме.
- `BLE001` в ignore: логгеры приходят в хендлеры инжекцией (`cl`,
  `ctx.glog`), ruff не считает их логгерами; 17 из 25 `except Exception`
  пишут трассу через `.exception()`, 8 деградируют намеренно с комментарием.
- По месту, с причиной: `TRY004` в загрузчике конфига (ошибка конфига — это
  `ValueError` для пользователя, не `TypeError`), `T201` в healthcheck (stdout
  и есть контракт), `DTZ006` в `message_db` (локальное время без зоны, как
  в текстовых логах рядом).
- `src` не задаётся: пакет называется `src`, дефолт `[".", "src"]` покрывает.
- Политика докстрингов проекта остаётся строже правил: документируется
  каждый символ, включая приватные.

## Why

- Полный набор, а не core: код перечитывается и живёт в Docker, `DOC`-секции
  и `ASYNC`/`TRY`/`LOG` там окупаются.
- Отвергнуто «`BLE001` по месту 25 `noqa`»: 17 из них — подавление ложного
  срабатывания инструмента, а не объяснение кода. Условие пересмотра: ruff
  научится распознавать логгеры по вызову `.exception()` на любом объекте.
- Отвергнуто «`TC001`–`TC003` руками»: 148 правок ради импорта, который на
  3.14 не стоит ничего.

## Cost

- `except Exception` без логирования ruff больше не поймает; ревью смотрит
  на это глазами.
- Точный пин `ruff==0.16.6`: апгрейд — отдельный коммит с прогоном
  `just fix` и чтением diff.
